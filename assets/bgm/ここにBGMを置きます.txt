【プリセットBGMの追加のしかた】

1. 使ってよいMP3ファイルを、このフォルダ（assets/bgm）に入れます。
   ※ファイル名は、半角の英数字にしてください（例: piano1.mp3）。

2. 同じフォルダの「list.json」を開き、次のように書きます。

   [
     { "file": "piano1.mp3", "name": "やさしいピアノ", "default": true }
   ]

   - file    … MP3のファイル名
   - name    … 設定画面に表示される曲名
   - default … true にした曲が、最初から選ばれた状態になります（1曲だけに付けてください）
   - 曲を複数入れるときは、カンマ(,)で区切って並べます。

3. GitHubに、assetsフォルダごとアップロードし直します。

【著作権についてのご注意】
このフォルダに置いたファイルは、公開サイト（GitHub Pages）から、誰でもダウンロードできる状態になります。
市販の楽曲や、動画サイトから取り出した音源は、公開してはいけません。
次のどれかに当てはまる曲だけを入れてください。

  - 自分たちで作った曲、または制作を依頼して、公開の許可を得た曲
  - 「素材そのものを再配布してよい」と、利用規約に書かれているフリー素材
    （「動画に使うのはOK」でも、「ファイルをそのまま公開するのはNG」という素材サイトが多いので、規約をご確認ください）
